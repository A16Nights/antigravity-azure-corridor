# 苍蓝回廊——会话与工作区管理（Azure Corridor）

当用户明确需要整理、搜索、收藏、置顶、归档、新建、跨工作区转移或删除 Antigravity 原生会话与工作区时，输出 `[苍蓝回廊](sidecar://azure-corridor/corridor/)` 侧边栏面板链接（Antigravity 2.35.1+ 会在回复出现该链接时自动在侧栏展开面板，平时无需主动附带）。

## 核心能力（100% 同步官方）
- **纯官方原生真源**：直连 Antigravity 2.35+ `product.v1.ConversationService` 与 `~/.gemini/config/projects/*.json`，标题、置顶、收藏、归档、官方标签、运行状态、新建与永久删除全部直接读写官方，不再维护非官方副本；快捷筛选栏支持自选钉选常用 `#标签`。
- **官方工作区、官方模型与跨区转移**：按官方工作区归类/筛选/新建会话，新建与转移默认自动识别并沿用原会话或当前活跃对话正在使用的官方具体模型；提供纯官方「跨工作区转移续聊」在目标工作区拉起续接会话（继承标题/标签/置顶/收藏并携带原会话引用）并可选自动归档原会话。
- **无限历史、正文检索与新手引导**：复用官方只读 FTS5 索引（支持 5000 条命中）与列表分页渲染，内置首次使用 5 步交互式新手引导与真实控件定位高亮。
